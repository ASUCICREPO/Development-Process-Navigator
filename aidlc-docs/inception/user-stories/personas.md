# ProcessCanvas — User Personas

## Persona 1: Instructor (Maria)
- **Role**: Instructor / course facilitator in a real-estate-development program.
- **Goals**:
  - Quickly build a sorting exercise that reflects the real-estate-development process.
  - Reuse and adapt content across cohorts using templates and saved configurations.
  - Run the exercise live in class and review how students performed.
- **Characteristics**:
  - Subject-matter expert; comfortable editing tables, not necessarily technical.
  - Time-constrained; values starting from templates over building from scratch.
- **Motivations**:
  - Help students internalize which activities belong in which process phase.
  - Get actionable insight into where students struggle (weak matches).
- **Pain Points**:
  - Manual setup and grading is tedious.
  - Hard to see, in the moment, how a class is doing during a live session.
- **Access**: Authenticated Instructor account; can author, save, run sessions, and view results for their own exercises and students.

## Persona 2: Student (Sam)
- **Role**: Learner enrolled in the instructor's course/cohort.
- **Goals**:
  - Understand the process by actively sorting activities into phases.
  - Get immediate, clear feedback and know what to improve.
  - Track personal progress across multiple attempts.
- **Characteristics**:
  - Uses the app in class (live) and self-paced; expects a smooth drag-and-drop UX.
  - May attempt an exercise multiple times to improve.
- **Motivations**:
  - Score well and understand reasoning behind feedback.
  - Reflect on the weakest area to deepen learning.
- **Pain Points**:
  - Generic feedback that doesn't explain *why* a placement was wrong.
  - Losing past attempts/history.
- **Access**: Authenticated Student account; can take exercises, submit, view own feedback and history. Cannot author or see other students' data.
